# BGA gastro funsion
  BGA Gastro Fusión is the largest gastronomic fair in the department of Santander, Colombia. This event has established itself as a key meeting point for the HORECA sector (Hotels, Restaurants, and Cafés), local entrepreneurs, and food lovers in the region.

## technologies used:
1. HTML5
2. SS3

## Project Structure

The project follows a simple semantic HTML structure:

- `<header>` → Title and main heading  
- `<nav>` → Navigation menu  
- `<main>` → Main content  
- `<footer>` → Contact and additional information

## Run the project locally

This is a static web project built with HTML and CSS, so no additional dependencies or installations are required.

1. Clone the repository
git clone https://github.com/joncoder14/bga.git
cd bga
2. Open the project

You can run the project in two simple ways:

Option A: Open directly in your browser
Locate the index.html file
Double click it

or

Right click → Open with → Your preferred browser
Option B: Use Live Server (recommended)

For a better development experience:

Open the project in VS Code
Install the Live Server extension
Right click on index.html
Select "Open with Live Server"

The project will run on a local server like:

http://localhost:5500
